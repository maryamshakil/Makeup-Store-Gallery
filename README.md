# Blush & Co. – Makeup Shop

## Project Description
Blush & Co. is a responsive makeup shopping webpage developed using HTML and CSS.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Google Fonts

## Project Files
- index.html – Main webpage structure.
- style.css – Styling and responsive product layout.

## Features
- Makeup product display
- Product cards
- Responsive product grid
- Hover effects
- Navigation bar
